Seasonote · 四季音乐转盘（Windows 0.4.0）

1. 完整解压本压缩包到一个固定文件夹，双击 Seasonote.exe。
   不要只把 exe 拿出来：web、dll 和其他文件均为运行所需资源。
2. 第一次启动会创建桌面 Seasonote 快捷方式。以后双击这个图标打开。
   可将解压后的文件夹整体移到喜欢的位置，再运行其中的 exe 更新快捷方式。
3. 鼠标移入转盘，右上角出现 ×；点击收起。双击桌面图标或点击任务栏通知区域（托盘）的 Seasonote 图标即可恢复。
4. 右击托盘图标可以打开开关窗口、居中、调整大小、暂停季节、切换速度/天气/画质、浏览器预览、创建桌面快捷方式和完全退出。
   托盘图标可能藏在任务栏的 ^ 展开区。关闭开关窗口不会退出摆件。

没有音乐时就是自然桌面摆件，不显示空的播放控件。
QQ 音乐安装并开始播放后，若播放器发布系统媒体信息，会自动显示封面、歌名和进度；暂停时保留，退出播放器后恢复纯摆件。
上一首、播放/暂停、下一首和进度拖动按播放器公布的能力启用。
安装QQ音乐本身不会自动播放歌曲。其他支持系统媒体会话的播放器也可能成为当前来源。
不需要填写 QQ 账号；Seasonote 不下载安装 QQ 音乐。

直接拖动摆件移动，四角等比缩放，位置大小自动保存。Shift 拖动盘面/指针改变季节，点击猫或蝴蝶可互动。
转盘位于 Windows 桌面层；普通应用窗口会遮住它，Win+D 显示桌面时可以看到。季节暂停时草地、猫、天气继续动。
浏览器预览保留四季、天气、画质、循环速度、背景、保存透明PNG和沉浸模式。关闭Seasonote时本地预览服务一并退出。
隐藏或退出 Seasonote 不会停止音乐。没有开机自动启动，不修改壁纸。

系统要求：Windows 10 2004 (19041) 或更高、Windows 11。常见Intel/AMD电脑用 x64 包；骁龙等ARM电脑用 ARM64 包。
本包包含 .NET 运行库；画面需要 Microsoft WebView2 Runtime。多数Windows系统已安装；缺失时应用会提供微软官方安装页面，安装后再次打开Seasonote。
此包由Mac上跨平台编译，已做代码/构建/媒体状态机验证，尚未经Windows实机确认。若画面、桌面层级或QQ音乐连接不正常，双击“导出诊断.cmd”，把生成的诊断文件和现象/截图交给制作人。

配置及错误日志：%LOCALAPPDATA%\Seasonote
