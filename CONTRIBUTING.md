# Contributing

Issues and pull requests are welcome. Start with the build and test steps in `docs/BUILD.md`. Keep the macOS / Windows media protocol aligned, keep renderer changes in the shared `seasons/` sources, and include reproduction steps for platform-specific fixes. Describe what was tested on real hardware versus simulated or cross-compiled.

Never commit player credentials, personal diagnostics, desktop screenshots with private information, third-party music/album artwork, build output or reference footage. Retain third-party copyright and license notices.
